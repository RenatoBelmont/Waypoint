# Waypoint

Conjunto de ferramentas para devs indie: GDC/GDD, Kanban, Codex, Notas, Mural, Árvore de Habilidades,
Mapas, Direção de Arte, Ferramentas de balanceamento e Saúde do projeto.

Vanilla JS, sem build: basta abrir `index.html` no navegador (ou servir a pasta, ex.
`python3 -m http.server`). Bibliotecas por CDN são opcionais — o app funciona offline com fallback.

Visão geral da arquitetura e convenções: [`docs/architecture-overview.md`](docs/architecture-overview.md).
